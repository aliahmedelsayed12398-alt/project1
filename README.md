# AI Customer Service Monorepo

This repository contains a multi-service platform for voice telephony and RAG-based analytics.

## Structure

- services/voice-telephony: telephony orchestration and voice workflows
- services/rag-analytics: retrieval-augmented analytics API and frontend
- shared: cross-service models, database schema, and NLU utilities

## Getting Started

1. Review the service-specific README files.
2. Configure environment variables from .env.example.
3. Start services with docker-compose.
